
## Pizz Sales Analysis using SQL

## Overview

This project focuses on analyzing pizza sales data using SQL to derive meaningful business insights. The objective was to design a structured database that efficiently stores, manages, and retrieves sales transactions, helping to understand sales performance, customer preferences, and revenue trends.



## Project Objective

• Develop a relational database schema to organize and store sales data.
 
 • Write SQL queries to analyze total revenue, top-selling pizzas, and cumulative sales trends.
 
 • Optimize query performance using joins, aggregate functions, subqueries, and indexing.
## Key Analyses Conducted

• Total Revenue Calculation: Analyzed overall sales performance.
 
 • Top-Selling Pizzas: Identified the most-ordered pizzas based on quantity and revenue.
 
 • Revenue Contribution: Measured the percentage contribution of each pizza type to total 
   revenue.
 
 • Sales Trends Over Time: Tracked cumulative revenue growth and seasonal variations.
## Technologies Used

 • SQL (MySQL)

 • Database Normalization & Indexing

 • Data Aggregation & Query Optimization

## Project Structure

• /database/ – SQL scripts for creating and structuring the database.

 • /queries/ – SQL queries used for data analysis and insights.
 
 • /reports/ – Summary of findings and key insights from the analysis.
